Blockcraft dev tools

← the game

Local helpers for editing the game's look and sound without restarting it. They load the game's own modules from src/, so what you see is exactly what the game paints and plays. See tools/README.md for how textures and sounds work.

Texture viewer & pixel editorEvery texture as the game paints it, mob previews, live reload when src/textures.js changes, and a pixel editor that exports code you can paste back. Sound boardPlay every sound effect (animals, blocks, explosions…) straight from src/audio.js, re-read on every click, plus a scratch pad for trying synth parameters.
