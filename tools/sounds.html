Scratch pad

Runs with s = the game's Sound object. Try parameters here, then copy them into src/audio.js. Ctrl+Enter plays.

Reference

s.tone({ freq, endFreq = freq, dur = 0.1, type = 'sine', gain = 0.2, delay = 0 })
    an oscillator gliding from freq to endFreq (Hz); type: sine | square | sawtooth | triangle
s.burst({ freq, q = 1, type = 'bandpass', dur = 0.2, gain = 0.4, attack = 0.004,
          delay = 0, rate = 1, sweepTo = 0 })
    filtered white noise; type: bandpass | lowpass | highpass; sweepTo glides the filter
Gains add up: keep the total under about 1. delay is in seconds from now.
